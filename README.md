# Angular Project - Functional Guide

## 1. Application Purpose

The goal of the application is to help each user find the most suitable partner based on their personality traits and interests.

---

## 2. User Roles

### Guest (Not Authenticated User)
- Can register  
- Can log in  

### Authenticated User
- Can edit their profile information  
- Can add additional interests and hobbies  
- Can answer personality questions to generate suitable matches  
- Can search for users based on specific criteria  
- Can upload and delete their own photos  
- Can react to their own photos as well as photos of other users (likes and comments)  
- Can discover matches for themselves based on their answers generated by the application  
- Can approve matches to start communication/chat  
- Can reject matches, and later, in the rejected matches list, choose to permanently delete the generated match or restore it to mutual matches  
- Can send messages to matches  

---

## 3. Public Features

### Pages

#### Public Pages
- Landing page (`/`) – Displays the main interface with app logo and links to register or log in
- Login page – Allows users to log in to their account  
- Registration page – Allows new users to create an account 

#### Authenticated User Features
- Edit profile information  
- Add hobbies and interests  
- Answer personality questions  
- Upload and delete photos  
- View personal dashboard  
- Like and comment on photos  
- Search users by criteria (age, location, etc.)  
- View and manage matches  
- View full profiles of matched users  
- Send messages to matches  

---

## 4. Main Application Flow

1. User opens the Landing page  
2. User logs in or registers  
3. User is redirected to Home page  
4. User edits profile information  
5. User adds hobbies and interests  
6. User answers personality questions  
7. User uploads photos and manages profile  
8. User searches for other users  
9. User interacts with photos (likes/comments)  
10. System generates matches (>50% compatibility)  
11. User approves or rejects matches  
12. Rejected matches can be restored or deleted  
13. Users can send messages to mutual matches

## 8. How to Run the Project

## Requirements
- Java 17 (JDK)
- Maven 

### 1. Clone the repository
Open the project in IntelliJ IDEA (root folder)

---

### 2. Backend

**Configuration (application.properties):**
- spring.datasource.username  
- spring.datasource.password

**Database setup:**
- Install and start MySQL  
- Create database: `matchly_db` (optional)

**Run the backend:**
- Open `matchly-backend`  
- Run `MatchlyApplication`
  
- Backend runs on: http://localhost:8080  

---

### 3. Frontend
- Open terminal in `matchly-app-frontend`  
- Run: `npm install`  
- Run: `ng serve`  
- Open: http://localhost:4200
